## 👨‍💻 About me

I'm a **second-year Software Engineering student at Kirirom Institute of Technology (KIT)** in Cambodia, and I build games on **Roblox** with **Luau**. I run **Eggcellent Studio**, my Roblox group and studio, along with its Discord community.

- 🚀 Passionate about software engineering, system architecture, and automation

## 🎮 My Roblox journey

| Stage | What it looked like |
| :-- | :-- |
| 🌱 **Getting started** | Learned Roblox Studio and Luau from scratch: scripting basics, events, and small experiments |
| 🧱 **Leveling up** | Moved to **object-oriented, modular code** with isolated, fault-tolerant base classes so one broken system can't take down the rest |
| 🔧 **Working like a studio** | Switched to **Rojo + Git/GitHub** for version control, with written specs and code reviews before anything ships |
| 🚢 **Shipping real systems** | Building multi-system games: **DataStore saving and data migrations**, **monetization** (developer products, game passes, gifting), **UI/UX**, **VFX**, plus lighting and sound polish |
| 🤖 **AI-assisted development** | Running a modern pipeline: **OpenAI Codex** as the builder, **Gemini** for specs and code review, and an asset pipeline with **Cloudflare Flux** concept art and **Blender**. I stay in charge of the design, testing, and final calls |
| 🎯 **Next** | Keep growing as a game developer and go deeper into game development in my studies |
